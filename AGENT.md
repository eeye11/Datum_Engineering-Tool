# Workspace Agent Guide

## Dynamics Workbench

- `src/features/workspace/dynamics/dynamics-hierarchy.js` declares the sidebar groups and marks Bodies, Kinematics, and Mechanical Elements as collapsible categories.
- `src/features/workspace/dynamics/dynamics-tools.js` declares each category's children and feature metadata; the shared `toolIcons` table in `src/components/layout/toolbar/tools.js` supplies category and child icons.
- `src/components/layout/toolbar/toolbar-render.js` renders the sidebar and registers tool-button click handlers. Its `expandedToolbarSections` state maps collapsible category IDs to booleans; category clicks toggle `aria-expanded` and the inline child list, while child clicks follow the existing tool activation path.
- `src/components/layout/toolbar/tool-menus.js` renders icon-bearing tool buttons and highlights a Dynamics category when one of its child tools is active.
- The inline child lists reuse the Statics `.drawing-inline-tools` presentation.
- `tests/dynamics-library.test.cjs` verifies all three categories expand/collapse inline with the expected icon-bearing child tools, and that child clicks use normal tool activation.
- Dynamics Trajectory has been removed from the Kinematics menu, tool definition registry, feature schemas, canvas/source renderers, and Dynamics tool-library manifest. Kinematics now contains Polar Vector and Angular Vector; the icon registry has no Trajectory entry. Other trajectory/path features outside Dynamics remain separate.

## Dynamics Particle

- `src/features/workspace/dynamics/dynamics-model.js` creates Particle geometry at the clicked position, assigns sequential names (`Particle A`, `Particle B`, ...), and initializes `engineering.massKg`, `engineering.massUnit`, and `engineering.initialVelocity`; its style starts filled with editable outline/fill settings.
- `src/features/workspace/geometry/geometry-creation.js` routes single-click Particle and Rigid Body placement through the shared commit/select flow, then activates Select so both tools are one-shot. The new object remains selected; existing shared selection and drag handlers allow it to be manipulated immediately, while its `locked` state prevents movement.
- `src/components/layout/panels/feature-schema.js` declares the Particle inspector groups and read/write schemas: Object (name and Fix), Physical Properties (mass with unit selection and initial-velocity components), Appearance (line style, outline, thickness, fill and opacity toggle), and Transform (live X/Y coordinates only).
- `src/components/layout/panels/features-editor.js` renders those schema groups and controls. Position input updates `geometry.position` live and commits one undoable edit on change/focus loss; other edits use the shared field commit path.
- `src/components/layout/panels/drawing-panel.js` switches to Features when a Dynamics Particle becomes selected. `src/shared/rendering/entities/draw-dynamics.js` draws the editable fill and outline; `src/shared/rendering/latex/source-writers/dynamics.js` writes the same fill/outline style. `src/shared/rendering/overlay-render.js` draws a fixed-anchor badge for locked particles, while the shared selection overlay provides the selection outline.
- `tests/dynamics-library.test.cjs` covers one-shot placement, coordinates and panel activation, inspector schema/editing, Fix handles, and the fixed-anchor badge.

## Dynamics Rigid Body

- `src/features/workspace/dynamics/dynamics-tools.js` registers Rigid Body as a click-placement tool. `src/features/workspace/dynamics/dynamics-model.js` reuses the shared `rigid-body` factory and Statics `RIGID_BODY_WIDTH`/`RIGID_BODY_HEIGHT` defaults, centering the 50 × 30 rectangle on the clicked position. `src/features/workspace/geometry/geometry-creation.js` returns the active tool to Select immediately after the body is committed and selected. It keeps Dynamics identity and stores mass/unit and manually entered mass moment of inertia in `engineering`.
- `src/shared/rendering/entities/draw-bodies.js`, `src/shared/geometry/feature-geometry.js`, and `src/shared/geometry/feature-handles.js` provide the shared Rigid Body renderer, geometry, resize handles, and rotation anchor used by Statics. `src/shared/rendering/entity-render.js` routes bodies through that renderer without a duplicate rectangle pass; `src/shared/rendering/svg-primitives.js` applies line/fill opacity. The common Fix lock hides handles and blocks canvas manipulation.
- `src/components/layout/panels/feature-schema.js` declares the Dynamics body’s Object, Physical Properties, Appearance, and Transform fields. Its schema includes Name/Fix, mass with kg/g/lb/slug units, editable dimensions and manual inertia (kg·m²), shared line/fill style controls, and live position/rotation fields. `src/components/layout/panels/features-editor.js` applies live coordinate/rotation edits as one undoable change; `src/components/layout/panels/drawing-panel.js` opens Features when the body is selected.
- `src/shared/rendering/latex/source-writers/dynamics.js` serializes the same shared body geometry and fill appearance. `tests/dynamics-library.test.cjs` covers centered placement, the inspector data contract, live transforms, and Fix handles.

## Dynamics Polar Vector

- `src/features/workspace/dynamics/dynamics-tools.js` keeps Polar Vector registered as a two-point span tool. `src/features/workspace/dynamics/dynamics-model.js` creates it from the dragged tail and tip, assigns sequential names (`Polar Vector 1`, ...), and initializes its magnitude, angle, representation, unit, attachment, and arrowhead style.
- `src/features/workspace/interaction/canvas-events.js` captures the Polar Vector pointer through release. Its `pointerdown`, `pointermove`, and `pointerup` listeners (including mouse, pen, and touch pointers) call `src/features/workspace/interaction/creation-drag.js` to run the common drag-creation session; `src/features/workspace/geometry/preview.js` renders the live tail-to-cursor arrow and reports its magnitude and normalized angle. `src/features/workspace/geometry/geometry-creation.js` commits/selects the vector after release and returns the active tool to Select.
- `src/features/workspace/interaction/hit-testing.js` picks the Polar Vector shaft and endpoint/arrowhead area by segment distance, allowing normal canvas selection to open Features via `src/components/layout/panels/drawing-panel.js`.
- `src/components/layout/panels/feature-schema.js` declares the Polar Vector Object, Vector Properties, Appearance, and Transform sections. The start/end coordinates are canonical: magnitude and angle edits resolve to a new tip using sine/cosine; Cartesian edits set the component deltas; origin edits translate both ends while preserving the vector. `src/features/workspace/interaction/drag.js` routes endpoint gizmo movement through `src/features/workspace/interaction/dynamics-handles.js` and keeps magnitude and angle synchronized.
- `src/components/layout/panels/features-editor.js` renders the attachment selector (Origin Point, Particle, Rigid Body, and reference points), unit selector, color swatch, and numeric controls. Magnitude, angle, components, and origin coordinates update the canvas live and commit as one edit. `src/shared/rendering/entities/draw-dynamics.js` reads the editable arrowhead size when drawing.
- `tests/dynamics-library.test.cjs` covers Polar Vector registration, drag placement/auto-select, selection-to-Features navigation, schema editing, vector calculations, and rendering/source consistency.

## Dynamics Angular Vector

- `src/features/workspace/dynamics/dynamics-tools.js` registers Angular Vector as a single-click point-placement tool. Clicking the workspace center creates one arc with a default radius, selects it, opens Features, and switches the active tool to Select. When the click hits a rigid body, reference point, or coordinate-system pivot, `src/features/workspace/geometry/geometry-creation.js` passes its id into `src/features/workspace/geometry/dynamics-creation.js` to store as `geometry.attachedTo`.
- `src/features/workspace/dynamics/dynamics-model.js` owns the data contract: `geometry.center`, `radius`, `startAngle`, `sweep`, `direction`, rotational type, magnitude/unit, and attachment id; the object also has a sequential name and Angular Vector Dynamics identity. The renderer in `src/shared/rendering/entities/draw-dynamics.js` draws the directed circular arc and tangent arrowhead, plus an ω/α magnitude label. The source writer serializes the arc from the same degree-based geometry.
- `src/features/workspace/interaction/hit-testing.js` samples the signed arc in world coordinates and tests pointer distance against its segments, so the visible arc and center are selectable. Polygon hit testing includes the interior of rigid bodies so an Angular Vector can attach when clicked on a body. The existing center handle updates `geometry.center`; `src/shared/geometry/feature-geometry.js` translates the center during ordinary canvas dragging. Fixed Dynamics lock behavior is shared with other Dynamics features.
- `src/components/layout/panels/feature-schema.js` declares Object (name and attachment), Rotational Properties (velocity/acceleration, magnitude/unit, and CW/CCW direction), Appearance (line style, color, thickness, arrowhead size), and Transform (center X/Y). `src/components/layout/panels/features-editor.js` applies magnitude and center edits live, renders those explicit center fields without adding generic transform offsets, and uses the shared commit-and-redraw path for unit, rotational type, and direction edits. Selection navigation in `src/components/layout/panels/drawing-panel.js` opens Features for Angular Vectors.
- `tests/dynamics-library.test.cjs` covers click placement, attachment, auto-select, arc hit-testing, Features activation, inspector schema edits, and center-handle synchronization.
