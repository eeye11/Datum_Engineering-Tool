# Callout balloons

Use **Annotate → Callouts → Callout**. Click the geometry to identify, then
click where the boxed marker should sit. Press-drag-release also works.

Markers start with the next available number. Type to replace it with a number,
letter, or other text. Enter or clicking outside finishes editing; Shift+Enter
adds a line. The tool returns to Select. Double-click a marker to edit it again,
or change its Text field in Features.

Drag the box to reposition it while leaving the arrow tip attached. Use the
arrow-tip handle to change its attachment; dropping it away from geometry makes
it a free marker. Snapped edge points follow geometry movement, rotation, and
resizing. Rectangle interior attachments retain their relative position.
Features displays the reference name or indicates a missing reference after
its target is deleted. Content and references survive save/load and undo/redo.

Leader is removed from the available toolbar and command catalogue. Existing
Leader objects remain loadable and editable for compatibility.
