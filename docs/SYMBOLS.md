# Symbols

Find **Symbol** under **Annotate → Text**. Arm the tool and click the canvas to
open its searchable library. Choose a glyph, then click its placement point.
Placement returns to Select.

The library contains 194 entries: existing engineering symbols, all 24 Greek
letters in both cases, Greek variants, arithmetic, comparisons, calculus, sets,
logic, number sets, arrows, and geometric notation. Search by a name, category,
glyph, or TeX command such as `theta`, `uppercase`, `Ψ`, or `\nabla`.

Selected glyphs retain their symbol IDs in saved drawings. Both source and SVG
exporters map added Unicode notation to TeX. Some legacy engineering glyphs use
the closest standard TeX symbol, as in the original exporter.
